# <center>面向对象核心概念</center>

---

## 封装

**目的**：隐藏内部实现，只暴露必要的接口。

```java
public class User {
    private String name;      // 私有字段，外部不能直接访问
    private int age;

    // 通过 getter/setter 控制访问
    public String getName() { return name; }
    public void setName(String name) { this.name = name; }

    public int getAge() { return age; }
    public void setAge(int age) {
        if (age < 0) throw new IllegalArgumentException("年龄不合法");
        this.age = age;       // 可以在 setter 中加校验逻辑
    }
}
```

## 继承

**目的**：代码复用，子类拥有父类的属性和方法。

```java
public class Animal {
    protected String name;

    public void eat() { System.out.println(name + " 在吃东西"); }
}

public class Dog extends Animal {
    public void bark() { System.out.println(name + " 汪汪叫"); }
}

// 使用
Dog dog = new Dog();
dog.name = "旺财";
dog.eat();    // 继承自 Animal
dog.bark();   // Dog 自己的方法
```

### 关键规则

| 规则 | 说明 |
|------|------|
| 单继承 | Java 只能继承一个父类 |
| Object 根类 | 所有类默认继承 Object |
| super | 调用父类构造器/方法 |
| 访问权限 | private → default → protected → public |

## 多态

**目的**：同一方法不同实现，提高扩展性。

```java
// 父类引用指向子类对象
Animal animal = new Dog();
animal.eat();   // 调用的是 Dog 的 eat（如果 Dog 重写了）
// animal.bark(); // ❌ 编译错误！父类引用不能调用子类特有方法
```

### 两个必要条件
1. **继承关系**（或实现接口）
2. **方法重写**

### 多态的实际应用场景

```java
// 支付系统 — 不同支付方式有不同实现
public interface Payment {
    void pay(BigDecimal amount);
}

public class WechatPay implements Payment {
    public void pay(BigDecimal amount) { /* 微信支付逻辑 */ }
}

public class AliPay implements Payment {
    public void pay(BigDecimal amount) { /* 支付宝支付逻辑 */ }
}

// 业务代码不关心具体支付方式，面向接口编程
public void checkout(Payment payment, BigDecimal amount) {
    payment.pay(amount);
}
```

## 抽象类 vs 接口

| | 抽象类 | 接口（Java8+） |
|------|--------|------|
| 关键字 | `abstract class` | `interface` |
| 构造器 | 有 | 无 |
| 方法 | 抽象方法 + 具体方法 | 抽象方法 + default 方法 + static 方法 |
| 字段 | 可以有实例字段 | 只能有常量（public static final） |
| 继承 | 单继承 | 可实现多个 |
| 使用场景 | "is-a" 关系，共享状态 | "can-do" 能力，定义契约 |

```java
// 抽象类：有共同状态
public abstract class BaseService {
    protected Logger log = LoggerFactory.getLogger(getClass());
    public abstract void doExecute();
}

// 接口：定义能力
public interface Cacheable {
    String getCacheKey();
    default long getTtl() { return 3600; }  // Java8 default 方法
}
```

## 设计原则速记

| 原则 | 一句话 |
|------|--------|
| 单一职责 | 一个类只做一件事 |
| 开闭原则 | 对扩展开放，对修改关闭 |
| 里氏替换 | 子类可以替换父类出现的地方 |
| 依赖倒置 | 面向接口编程，不面向实现编程 |
| 接口隔离 | 接口尽量小，不强迫实现不需要的方法 |

---

> **核心思想**：**封装变化，面向接口编程**。理解这八个字，面向对象就通了。

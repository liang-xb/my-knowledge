# <center>Java 学习路线</center>

---

## 整体路线图

```
Java 基础语法  →  面向对象  →  常用类库  →  异常/IO/多线程/集合
                                              ↓
SpringBoot 实战  ←  数据库 + JDBC  ←  网络编程 + 反射  ←  Java8 新特性
```

---

## 第一阶段：Java 基础 `约 4~6 周`

**目标：能独立写出控制台小程序**

| 内容 | 重点 |
|------|------|
| 基本语法 | 变量、运算符、流程控制（if/for/while） |
| 数组 | 一维数组、二维数组、冒泡排序 |
| 面向对象基础 | 类与对象、封装、继承、多态 |
| 面向对象中级 | 包、访问修饰符、super、方法重写 |

**检验标准**：不看代码能自己写出一个"学生管理系统"（增删改查 + 控制台交互）。

---

## 第二阶段：进阶提升 `约 6~8 周`

**目标：掌握 Java 核心类库和常用工具**

| 内容 | 重点 |
|------|------|
| 面向对象高级 | 类变量、内部类、枚举、注解 |
| 异常处理 | try-catch-finally、自定义异常 |
| 常用类 | String、StringBuilder、包装类、日期类 |
| 集合框架 | List、Set、Map、Collections 工具类 |
| IO 流 | 字节流、字符流、缓冲流、序列化 |
| 多线程 | Thread、Runnable、线程同步、线程池 |

**检验标准**：能看懂 JDK 源码中常用类的实现思路。

---

## 第三阶段：Java 高级 `约 4~6 周`

**目标：为框架学习做准备**

| 内容 | 重点 |
|------|------|
| 泛型 | 泛型类、泛型方法、通配符 |
| 反射 | Class 类、获取字段/方法、动态代理 |
| 注解 | 元注解、自定义注解 |
| 网络编程 | TCP/UDP、Socket |
| JDBC | 连接数据库、PreparedStatement、事务 |
| Java8 新特性 | Lambda、Stream、Optional |

**检验标准**：能理解 MyBatis、Spring 等框架底层用了哪些 Java 特性。

---

## 学完 JavaSE 之后

| 阶段 | 内容 |
|------|------|
| 数据库 | MySQL → Redis |
| 框架 | MyBatis → Spring → SpringBoot → MyBatis Plus |
| 微服务 | SpringCloud、RabbitMQ、Elasticsearch |
| DevOps | Linux、Docker、Git、Nginx |

---

> **建议**：每个阶段至少动手写 2~3 个小项目，光看不练等于白学。基础语法阶段就写控制台项目，进阶阶段可以写网络聊天室、文件管理器，高级阶段写一个 JDBC + 控制台的 CRUD 系统。

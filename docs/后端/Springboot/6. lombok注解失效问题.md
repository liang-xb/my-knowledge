# Lombok 注解失效问题

---

## 问题现象

SpringBoot 项目成功启动但前端无法显示数据，或编译时报 lombok 相关错误。

## 原因分析

基于最新版本 SpringBoot 官方骨架创建项目并勾选 lombok 依赖后，pom.xml 中会引入 `maven-compiler-plugin` 插件，该插件可能导致 lombok 注解失效。

## 解决方案

**第一步：删除 `maven-compiler-plugin` 插件。**

**第二步：为 lombok 依赖添加版本号：**

```xml
<dependency>
    <groupId>org.projectlombok</groupId>
    <artifactId>lombok</artifactId>
    <version>1.18.30</version>
    <scope>provided</scope>
</dependency>
```

> 修改 pom.xml 后需刷新 Maven 依赖才能生效。可在 IDEA 右侧 Maven 面板点击刷新按钮，或右键项目 → Maven → Reload Project。

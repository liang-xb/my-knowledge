# Bean 管理

---

## Bean 的作用域

IoC 容器中的 bean 默认使用 **singleton（单例）** 作用域。

| 作用域 | 说明 |
| ------ | ---- |
| `singleton` | 单例，IoC 容器中只有一个实例（默认） |
| `prototype` | 多例，每次获取都创建新实例 |

### @Scope 注解

```java
@Scope("prototype")
@RestController
public class DeptController { ... }
```

### @Lazy 注解

默认 singleton bean 在容器启动时创建，使用 `@Lazy` 可以**延迟初始化**（延迟到第一次使用时创建）。

## prototype 使用场景

适用于需要保存状态数据的场景。例如：对象需要在当次操作中记录错误次数，为防止多线程操作同一对象导致数据混乱，应使用多例。

```java
@Scope("prototype")
@Component
public class DataProcessor {
    private List<EmpModel> dataList = new ArrayList<>();
    private Integer errCount = 0;
    // ...
}
```

### Bean 的线程安全性

| 类型 | 特征 | 线程安全性 |
| ---- | ---- | ---------- |
| 无状态 Bean | 内部不保存状态信息 | 线程安全 |
| 有状态 Bean | 内部保存状态信息 | 线程不安全 |

> 实际开发中绝大部分 bean 是单例的，不需要配置 scope 属性。

## 引入第三方 Bean

第三方依赖中的类无法使用 `@Component` 声明 bean，需使用 **`@Bean`** 注解。

> `@Bean` 注解的方法返回值自动交给 IoC 容器管理。若不指定名称，默认 bean 名为方法名。若第三方 bean 需要依赖其他 bean，直接在方法形参中声明即可（自动装配）。

### 在启动类中声明

```java
@SpringBootApplication
public class TliasWebManagementApplication {
    public static void main(String[] args) {
        SpringApplication.run(TliasWebManagementApplication.class, args);
    }

    @Bean
    public AliyunOSSOperator aliyunOSSOperator(AliyunOSSProperties ossProperties) {
        return new AliyunOSSOperator(ossProperties);
    }
}
```

### 通过 @Configuration 集中管理（推荐）

```java
@Configuration
public class OSSConfig {
    @Bean
    public AliyunOSSOperator aliyunOSSOperator(AliyunOSSProperties ossProperties) {
        return new AliyunOSSOperator(ossProperties);
    }
}
```

## 获取 Bean 对象

`ApplicationContext` 是 Spring 核心容器接口，通过 `getBean()` 获取管理的 Bean：

```java
@SpringBootTest
class SpringbootWebConfig2ApplicationTests {
    @Autowired
    private ApplicationContext applicationContext;

    @Test
    public void testScope() {
        for (int i = 0; i < 10; i++) {
            DeptController deptController = applicationContext.getBean(DeptController.class);
            System.out.println(deptController);
        }
    }
}
```

# 自定义 starter

---

## starter 介绍

在实际项目开发中，很多第三方技术官方没有提供 SpringBoot 整合的 starter 起步依赖。我们可以将通用组件封装为 starter，提供给多个项目组使用。

### 命名规范

| 类型 | 命名格式 |
| ---- | -------- |
| 官方 starter | `spring-boot-starter-xxx` |
| 第三方 starter | `xxx-spring-boot-starter` |

### 模块结构

一个完整的 starter 通常包含两个模块：

- **starter 模块**：依赖管理，将 autoconfigure 模块和所有需要的依赖统一管理
- **autoconfigure 模块**：自动配置，编写自动配置核心代码

### 自动配置原理

在 autoconfigure 模块的 `META-INF/spring/org.springframework.boot.autoconfigure.AutoConfiguration.imports` 中配置自动配置类的全类名，SpringBoot 启动时会加载该文件中的配置类并注册 bean 到 IoC 容器。

## 案例：自定义阿里云 OSS Starter

**需求**：自定义 `aliyun-oss-spring-boot-starter`，引入后直接注入 `AliyunOSSOperator` 即可使用阿里云 OSS。

### 实现步骤

**第 1 步：创建 starter 模块 `aliyun-oss-spring-boot-starter`**

仅保留 pom.xml，管理依赖并引入 autoconfigure 模块：

```xml
<dependencies>
    <dependency>
        <groupId>org.springframework.boot</groupId>
        <artifactId>spring-boot-starter</artifactId>
    </dependency>
    <dependency>
        <groupId>com.aliyun.oss</groupId>
        <artifactId>aliyun-oss-spring-boot-autoconfigure</artifactId>
        <version>0.0.1-SNAPSHOT</version>
    </dependency>
</dependencies>
```

**第 2 步：创建 autoconfigure 模块 `aliyun-oss-spring-boot-autoconfigure`**

包含自动配置类和 OSS 工具代码，pom.xml 中引入阿里云 OSS SDK 依赖。

**第 3 步：编写自动配置类**

由于 `@Component` 注解不会被扫描到，改为在配置类中通过 `@Bean` 声明：

```java
@Configuration
@EnableConfigurationProperties(AliyunOSSProperties.class)
public class AliyunOSSAutoConfiguration {
    @Bean
    public AliyunOSSOperator aliyunOSSOperator(AliyunOSSProperties aliyunOSSProperties) {
        return new AliyunOSSOperator(aliyunOSSProperties);
    }
}
```

**第 4 步：创建自动配置文件**

在 `resources/META-INF/spring/` 下创建 `org.springframework.boot.autoconfigure.AutoConfiguration.imports`：

```
com.aliyun.oss.AliyunOSSAutoConfiguration
```

### 使用

其他项目引入 starter 后，在 `application.yml` 配置 OSS 信息，直接 `@Autowired` 注入 `AliyunOSSOperator` 即可使用：

```java
@RestController
public class UploadController {
    @Autowired
    private AliyunOSSOperator aliyunOSSOperator;

    @PostMapping("/upload")
    public String upload(MultipartFile image) throws Exception {
        return aliyunOSSOperator.upload(image.getBytes(), image.getOriginalFilename());
    }
}
```

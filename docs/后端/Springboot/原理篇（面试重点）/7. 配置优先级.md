# 配置优先级

---

## 三种配置文件

SpringBoot 支持三种配置文件格式：

- `application.properties`
- `application.yml`
- `application.yaml`

### 优先级（从高到低）

```
properties > yml > yaml
```

> 虽然支持多种格式，但推荐统一使用 **yml**（主流）。

## Java 系统属性与命令行参数

```bash
# Java 系统属性
-Dserver.port=9000

# 命令行参数
--server.port=10010
```

## 优先级总结

```
命令行参数 > 系统属性参数 > properties > yml > yaml
```

## jar 包配置

项目打包上线后，可通过命令行设置配置：

```bash
java -Dserver.port=9000 -jar XXXXX.jar --server.port=10010
```

> 命令行参数的优先级最高。

### 打包

执行 Maven 打包指令 `package`，需要 `spring-boot-maven-plugin` 插件（基于官网骨架创建会自动添加）。

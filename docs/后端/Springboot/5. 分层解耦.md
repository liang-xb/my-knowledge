# 分层解耦

---

## 问题引入

三层架构中 Controller 直接 `new ServiceImpl()`、Service 直接 `new DaoImpl()`，当需要更换实现类时必须修改源码，这就是层与层之间**耦合**了。

## 基本概念

- **内聚**：模块内部的功能联系
- **耦合**：层/模块之间的依赖关联程度

软件设计原则：**高内聚低耦合**。

## 解耦思路

1. 不能在 Controller 中使用 `new` 创建对象
2. 提供一个**容器**来存储和管理对象
3. 应用从容器中获取所需对象

## IOC（控制反转）

将对象的控制权交给 Spring IoC 容器管理，IoC 容器创建的对象称为 **Bean**。

### Bean 声明注解

| 注解 | 说明 |
| ---- | ---- |
| `@Component` | 通用组件 |
| `@Controller` | 控制层（声明控制器 bean 只能用此注解） |
| `@Service` | 业务逻辑层 |
| `@Repository` | 数据访问层 |

> 声明 bean 时可通过 `value` 属性指定 bean 名称，默认为**类名首字母小写**。

### 组件扫描

bean 声明注解起作用的前提是能被 `@ComponentScan` 扫描到。`@SpringBootApplication` 已包含此注解，默认扫描**启动类所在包及其子包**。

## DI（依赖注入）

### @Autowired 三种用法

**（1）属性注入：**

```java
@RestController
public class UserController {
    @Autowired
    private UserService userService;
}
```

> 优点：简洁高效。缺点：隐藏依赖关系，可能破坏封装性。

**（2）构造器注入（官方推荐）：**

```java
@RestController
public class UserController {
    private final UserService userService;

    @Autowired  // 只有一个构造器时可省略
    public UserController(UserService userService) {
        this.userService = userService;
    }
}
```

> 优点：依赖清晰，提高安全性。

**（3）Setter 注入：**

```java
@RestController
public class UserController {
    private UserService userService;

    @Autowired
    public void setUserService(UserService userService) {
        this.userService = userService;
    }
}
```

### 多个相同类型 Bean 的解决方案

| 方案 | 说明 |
| ---- | ---- |
| `@Primary` | 存在多个同类型 Bean 时确定默认实现 |
| `@Qualifier("name")` | 指定注入的 bean 名称，须配合 `@Autowired` 使用 |
| `@Resource(name="name")` | JDK 注解，按名称注入 |

### @Autowired vs @Resource

| 区别 | @Autowired | @Resource |
| ---- | ---------- | --------- |
| 来源 | Spring 框架 | JDK 提供 |
| 注入方式 | 默认按**类型**注入 | 按**名称**注入 |

### 同名 Controller 注入冲突

Spring 默认以类名首字母小写作为 Bean 名称，类名相同的 Controller 会导致冲突。通过 `@RestController` 的 `value` 属性自定义 bean 名称可避免。

## 案例实现

**（1）将 Service 及 Dao 层实现类交给 IoC 容器管理：**

```java
@Component
public class UserDaoImpl implements UserDao { ... }

@Component
public class UserServiceImpl implements UserService { ... }
```

**（2）为 Controller 及 Service 注入依赖：**

```java
@RestController
public class UserController {
    @Autowired
    private UserService userService;

    @RequestMapping("/list")
    public List<User> list() {
        return userService.findAll();
    }
}
```

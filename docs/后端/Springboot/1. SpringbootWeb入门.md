# SpringBoot Web 入门

---

## 基本概念

### 静态资源与动态资源

- **静态资源**：HTML、CSS、JS、图片等，存储在服务器上不会根据用户请求变化的内容
- **动态资源**：在服务器端根据用户请求动态生成，每次请求可能返回不同内容

如今企业开发中，直接基于 **Spring 框架**来构建动态资源，部署在 Tomcat 等 Web 服务器中运行。

### BS 架构 vs CS 架构

| 架构 | 模式 | 优点 | 缺点 |
| ---- | ---- | ---- | ---- |
| BS (Browser/Server) | 浏览器 ⇄ 服务器，客户端只需浏览器 | 维护方便 | 体验一般 |
| CS (Client/Server) | 需单独开发客户端 | 体验好 | 开发维护麻烦 |

### Spring 生态

Spring 官网：<https://spring.io>

Spring 已形成完整的开发生态圈，核心是 **SpringFramework**。其他 Spring 家族技术都基于 SpringFramework，提供依赖注入、事务管理、Web 开发、数据访问等功能。

直接基于 SpringFramework 开发存在**配置繁琐、入门难度大**的问题。**Spring Boot** 能够快速构建应用，特点：**简化配置、快速开发**。

## 入门程序

需求：浏览器访问 `/hello` 后，返回字符串 `"Hello xxx ~"`。

```java
@RestController  // 标识当前类是一个请求处理类
public class HelloController {
    @RequestMapping("/hello")  // 标识请求路径
    public String hello(String name) {
        System.out.println("HelloController ... hello：" + name);
        return "Hello " + name;
    }
}
```

浏览器访问：`http://localhost:8080/hello?name=jackonling`

> 如果连接 Spring 脚手架超时，可使用阿里云脚手架：<https://start.aliyun.com>

## 项目启动分析

**为什么一个 main 方法就能启动 Web 应用？**

创建项目时选择了 `spring-boot-starter-web`，它依赖了 `spring-boot-starter-tomcat`。通过 Maven 依赖传递，项目中已内嵌 Tomcat。运行 main 方法就是启动内嵌 Tomcat，项目自动部署到该服务器，默认占用 8080 端口。

## 起步依赖

起步依赖本质是一组预定义的依赖项集合，简化配置和集成。

- `spring-boot-starter-web`：Web 开发所需常见依赖
- `spring-boot-starter-test`：单元测试所需常见依赖

官方 starter 列表：<https://docs.spring.io/spring-boot/docs/3.1.3/reference/htmlsingle/#using.build-systems.starters>

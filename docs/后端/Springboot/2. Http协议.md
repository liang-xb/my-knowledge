# HTTP 协议

---

## 基本介绍

HTTP（Hyper Text Transfer Protocol，超文本传输协议）规定了浏览器与服务器之间数据传输的规则。浏览器发送请求数据和服务器返回响应数据都必须按照固定格式。

## 协议特点

1. **基于 TCP 协议**：面向连接（三次握手），可靠传输
2. **基于请求-响应模型**：一次请求对应一次响应，无请求则无响应
3. **无状态协议**：每次请求-响应独立，不记录任何信息
   - 优点：速度快
   - 缺点：多次请求间不能共享数据（通过 Cookie、Session 等会话技术解决）

## 请求协议

请求包含三部分：**请求行、请求头、请求体**。

### 请求行

格式：`请求方式 资源路径 协议/版本`

```
GET /brand/findAll?name=OPPO&status=1 HTTP/1.1
```

- 请求路径：`/brand/findAll`
- 请求参数：`name=OPPO&status=1`（key=value 形式，多个用 `&` 连接，与路径用 `?` 分隔）

### 请求头

格式为 `key: value`，常见请求头：`Host`、`User-Agent`、`Content-Type`、`Accept` 等。

### 请求体

POST 请求参数存储在请求体中，GET 请求参数在请求行中（无请求体）。

### GET vs POST

| 方式 | 参数位置 | 大小限制 | 安全性 |
| ---- | -------- | -------- | ------ |
| GET | 请求行（URL 中） | 有限 | 低（参数暴露在 URL） |
| POST | 请求体 | 较大 | 相对较高 |

### 获取请求数据

Tomcat 将 HTTP 请求解析后封装为 `HttpServletRequest` 对象：

```java
@RestController
public class RequestController {
    @RequestMapping("/request")
    public String request(HttpServletRequest request) {
        String name = request.getParameter("name");       // 获取请求参数
        String uri = request.getRequestURI();             // 获取请求路径
        String url = request.getRequestURL().toString();   // 获取请求 URL
        String method = request.getMethod();              // 获取请求方式
        String header = request.getHeader("User-Agent");  // 获取请求头
        return "request success";
    }
}
```

## 响应协议

响应同样包含三部分：**响应行、响应头、响应体**。

### 响应行

格式：`协议/版本 响应状态码 状态码描述`

```
HTTP/1.1 200 OK
```

### 常见响应头

| 头 | 说明 |
| ---- | ---- |
| Content-Type | 响应内容的类型，如 `text/html`、`application/json` |
| Content-Length | 响应内容的长度（字节数） |
| Cache-Control | 缓存策略，如 `max-age=300` |
| Set-Cookie | 为当前页面所在域设置 Cookie |

### 常见状态码

| 状态码 | 说明 |
| ------ | ---- |
| 200 | OK，请求成功 |
| 301/302 | 重定向 |
| 304 | 未修改（缓存） |
| 400 | Bad Request，请求参数有误 |
| 401 | Unauthorized，未认证 |
| 403 | Forbidden，无权限 |
| 404 | Not Found，资源不存在 |
| 500 | Internal Server Error，服务器内部异常 |

### 设置响应数据

```java
// 方式一：基于 HttpServletResponse
@RequestMapping("/response")
public void response(HttpServletResponse response) throws IOException {
    response.setStatus(401);
    response.setHeader("name", "itcast");
    response.setContentType("text/html;charset=utf-8");
    response.getWriter().write("<h1>hello response</h1>");
}

// 方式二：基于 ResponseEntity
@RequestMapping("/response2")
public ResponseEntity<String> response2() {
    return ResponseEntity.status(401).header("name", "itcast")
            .body("<h1>hello response</h1>");
}
```

> 响应状态码和响应头通常无需手动设置，服务器会根据处理逻辑自动设置。

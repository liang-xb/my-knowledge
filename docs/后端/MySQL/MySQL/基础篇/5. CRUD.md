# CRUD

---

> **C**：Create（创建）— 向数据库中插入新的数据记录
> **R**：Read（读取）— 从数据库中查询或检索数据记录
> **U**：Update（更新）— 修改数据库中已存在的数据记录
> **D**：Delete（删除）— 从数据库中移除数据记录

## Insert

### 添加单条记录

指令：**INSERT INTO （表名）（列名1, 列名2...） VALUES （值1, 值2, ...）**

案例：已知表结构如下，插入一组数据。

![插入案例：表结构](插入案例：表结构.png)

```sql
INSERT INTO employee
(id, user_name, birthday, entry_date, job, salary, `resume`)
VALUES
(1, '张伟', '1990-05-20', '2020-08-15', '软件工程师', 12000, '计算机科学硕士');
```

### 添加多条记录

使用逗号分隔多组数据：

```sql
INSERT INTO employee
(id, user_name, birthday, entry_date, job, salary, `resume`)
VALUES
(1, '张伟', '1990-05-20', '2020-08-15', '软件工程师', 12000, '计算机科学硕士'),
(2, '李娜', '1988-03-10', '2018-05-01', '数据分析师', 15000, '统计学博士');
```

## Update

指令：**UPDATE 表名 SET 字段 = 更新值 （WHERE 字段 = 指定字段值）**

::: warning 注意
如果不指定 WHERE，会修改全部字段值，慎用！
:::

**修改多个值：**

```sql
UPDATE employee SET job='测试工程师', birthday='1990-05-30' WHERE user_name='李强';
```

**在原基础上修改：** `字段 = 字段（操作）`，例如 `salary = salary * 2` 表示工资翻倍。

```sql
UPDATE employee SET salary=salary + 1000 WHERE user_name='刘欣';
```

**使用细节：**

1. UPDATE 语法可以用新值更新原有表行中的各列
2. SET 子句指定要修改哪些列和要给予哪些值
3. WHERE 子句指定应 **更新哪些行**。如没有 WHERE 子句，则更新所有的行，**一定要小心**
4. 如果需要 **修改多个字段**，可以通过 `SET 字段1=值1, 字段2=值2...`

## Delete

指令：**DELETE FROM 表名 WHERE 字段 = 指定字段值**

**删除指定信息：**

```sql
DELETE FROM employee WHERE id=1;
```

**删除全部表信息：**

```sql
DELETE FROM 表名;
```

**使用细节：**

1. 如果不使用 **WHERE** 子句，将 **删除** 表中 **所有** 数据
2. Delete 语句 **不能删除某一列** 的值（可使用 **UPDATE** 设置为 `null` 或者 `''`）
3. 使用 **DELETE** 语句 **仅删除记录**，不删除表本身。要删除表，使用 **DROP TABLE** 语句

## Select

### 基本介绍

指令：**SELECT （DISTINCT）*（或者）（column...） FROM 表名 (WHERE 过滤条件)**

![select基本使用](select基本使用.png)

> 去重说明：**每个字段值都相同，才会去重**。

### 查询全部表数据

**方法一：** 使用 `*` 号

```sql
SELECT * FROM employee;
```

**方法二：** 列出所有列（推荐写法，效率更高且直观）

```sql
SELECT id,user_name,birthday,entry_date,job,salary,resume FROM employee;
```

### 查询指定列数据

```sql
SELECT id,user_name FROM employee;
```

### AS 起别名

`SELECT 列名 AS 别名 FROM 表名`，AS 关键字可以省略。别名可以直接写，但如果别名 **中间有空格**，需要使用 **单引号包裹**。不会改变原来的字段，但显示时会 **以别名显示**。

```sql
SELECT id AS '编号' FROM employee;
```

### DISTINCT 去重

**每个字段值都相同，才会去重**：

```sql
SELECT DISTINCT * FROM employee;
```

### 运算符

![select运算符](select运算符.png)

**LIKE 模糊查询：**

- `%`：表示 **0 到多个字符**
- `_`：表示 **单个字符**

**注意点：**

1. **表达式需要使用括号包起来**
2. BETWEEN ... AND ... 是 **左闭右闭** 的
3. WHERE 列字段 LIKE '指定值%'，% 是一个通配符，表示任意数量的字符
4. **IN（多个值）**：表示被查询的数据值只要是 IN 中的值即视为符合条件的值（**等价于用 OR 连接**）
5. 如果有多个过滤条件，则全部使用 **AND** 连接

**案例一：计算总分**

```sql
SELECT (chinese + math + english) AS total_score FROM employee;
```

**案例二：过滤查询**

```sql
SELECT (chinese + math + english) AS total_score
FROM employee
WHERE (chinese + math + english) > 200;
```

**案例三：BETWEEN ... AND ...**

```sql
SELECT (chinese + math + english) AS total_score
FROM employee
WHERE (chinese + math + english) BETWEEN 200 AND 300;
```

**案例四：模糊查询 — 查询姓"王"的**

```sql
SELECT (chinese + math + english) AS total_score
FROM employee
WHERE (chinese + math + english) BETWEEN 200 AND 300
AND user_name LIKE '王%';
```

**案例五：模糊查询 — 第二个字为"王"**

```sql
SELECT * FROM `user` WHERE `user_name` LIKE '_王%';
```

**案例六：模糊查询 — 包含"王"**

```sql
SELECT * FROM `user` WHERE `user_name` LIKE '%王%';
```

**案例七：使用 IN 设置筛选条件**

```sql
SELECT * FROM employee WHERE resume IN ('计算机科学硕士', '信息工程学士');
```

### 分组查询

`SELECT 函数/列字段... FROM 表名 GROUP BY 分组名 HAVING 分组的限制条件...`

- 分组之后（**支持多字段分组**），查询的字段一般为聚合函数和分组字段，查询其他字段无任何意义
- 执行顺序：WHERE → 聚合函数 → HAVING

**WHERE 和 HAVING 的区别：**

1. 执行时机不同：WHERE 是分组之前进行过滤，不满足 WHERE 条件不参与分组；HAVING 是分组之后对结果进行过滤
2. 判断条件不同：**WHERE 不能对聚合函数进行判断**，而 HAVING 可以

**案例一：按岗位分类查询平均工资、最高工资和最低工资**

```sql
SELECT job, AVG(Salary), MAX(Salary), MIN(Salary)
FROM employee
GROUP BY job;
```

**案例二：在案例一的基础上只显示平均工资大于一万的**

```sql
SELECT job,AVG(Salary), MAX(Salary),MIN(Salary)
FROM employee
GROUP BY job HAVING AVG(Salary) > 10000;
```

### 排序

1. ORDER BY 指定排序的列（**可以是多列**），排序的列既可以是表中的列名，也可以是 SELECT 语句后指定的列名
2. ASC（升序，**默认**），DESC（降序）
3. ORDER BY 子句应位于 SELECT 语句的结尾
4. 如果是 **多字段** 排序，当 **第一个** 字段值 **相同** 时，才会根据 **第二个** 字段进行 **排序**

**案例一：ORDER BY 指定多列排序**

```sql
SELECT * FROM `user` ORDER BY `group`,`salary` ASC;
```

**案例二：升序排列**

```sql
SELECT (chinese + math + english) AS total_score
FROM employee
WHERE (chinese + math + english) > 200
ORDER BY total_score ASC;
```

**案例三：降序排列**

```sql
SELECT (chinese + math + english) AS total_score
FROM employee
WHERE (chinese + math + english) > 200
ORDER BY total_score DESC;
```

### WHERE

指定查询条件，如果有多个过滤条件，则全部使用 **AND** 连接。**可以比较时间**，日期需要使用 **单引号包裹**，日期格式为 0000-00-00，**不要省略 0**。

**案例一：查询姓王的薪水，按照从高到低排序**

```sql
SELECT user_name,Salary FROM employee WHERE `user_name` LIKE '王%' ORDER BY Salary DESC;
```

**案例二：查询 1992.1.1 后出生的用户**

```sql
SELECT * FROM `user` WHERE `birth` > '1992-01-01';
```

### 分页查询

1. 语法：`SELECT ... LIMIT start, rows`
2. start 是起始索引，**从 0 开始**
3. 表示从起始索引开始，查询 rows 行记录
4. 公式：**起始索引 start = (当前页码 - 1) × 每页显示记录数**

案例：一共 100 条记录，一页显示 5 条记录，查询第五页的记录。

> 公式计算：起始索引 start = (5 - 1) × 5 = 20

```sql
SELECT * FROM `user` LIMIT 20,5;
```

### 语句顺序

**编写顺序：** SELECT → FROM → WHERE → GROUP BY → HAVING → ORDER BY → LIMIT

**执行顺序：** FROM → WHERE → GROUP BY → HAVING → SELECT → ORDER BY → LIMIT

**案例：** 统计各部门平均工资，大于 1000 的，按照平均工资从高到低排序，一共 6 行记录，取第 3-6 行。

```sql
SELECT deptno,AVG(sal) AS avg_sal FROM emp
GROUP BY deptno
HAVING avg_sal > 1000
ORDER BY avg_sal DESC
LIMIT 2,4;
```

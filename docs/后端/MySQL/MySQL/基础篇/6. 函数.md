## 统计函数

### COUNT

`SELECT COUNT（* 或者 (DISTINCT)列字段） FROM 表名 WHERE ...`

- **COUNT(\*)**：统计总记录数（**推荐使用，底层做了优化**）
- **COUNT(常量)**：统计总记录数
- **COUNT(列名)**：统计满足条件的某列有多少个，但 **不会统计 NULL 值**

**案例一：统计总人数**

```sql
SELECT COUNT(*) FROM employee;
```

**案例二：统计薪水大于一万的人数**

```sql
SELECT COUNT('Salary') FROM employee WHERE Salary > 10000;
```

**案例三：统计有多少种部门管理者（需要去重）**

```sql
SELECT COUNT(DISTINCT('manager_id')) FROM `company`;
```

### SUM

`SELECT SUM（列字段 或者 表达式） FROM 表名 WHERE ...`

```sql
-- 统计全班数学总分
SELECT SUM(math) FROM employee;

-- 统计平均薪水
SELECT SUM(Salary) / COUNT(*) FROM employee;
```

### AVG

`SELECT AVG（列字段 或者 表达式） FROM 表名 WHERE ...`

```sql
-- 统计平均薪水
SELECT AVG(Salary) FROM employee;

-- 统计平均总分
SELECT AVG(chinese + math + english) FROM employee;
```

### MAX / MIN

```sql
-- 查询薪水最高的员工
SELECT MAX(Salary) FROM employee;

-- 查询薪水最低的员工
SELECT MIN(Salary) FROM employee;
```

## 字符串函数

![字符串函数方法](字符串函数方法.png)

![字符串函数](字符串函数.png)

**说明：**

- **DUAL 亚元表**是系统表，可以作为 **测试表** 使用
- SUBSTRING：**起始位置为 1**，如果不写结束位置，默认是从开始位置 **截取到** 字符串 **末尾**
- STRCMP：返回的结果值和 Java 字符串中的 CMP 函数规则一致
- LENGTH：返回的 **长度按字节计算**

```sql
SELECT CHARSET(user_name) FROM employee;              -- 返回字段的字符集
SELECT LENGTH('王强') FROM DUAL;                       -- 返回字符串的长度（按字节）
SELECT CONCAT(user_name,'的工作：',job) FROM employee;  -- 字符串拼接
SELECT INSTR('jacksonling','ling') FROM DUAL;          -- 子串在主串中出现的位置
SELECT UCASE(user_name) FROM employee;                 -- 转大写
SELECT LCASE(user_name) FROM employee;                 -- 转小写
SELECT REPLACE(user_name, '刘洋', 'lucy') FROM employee;-- 替换
SELECT STRCMP('app','bpp') FROM DUAL;                  -- 字符串比较
SELECT SUBSTRING(user_name, 1,1) FROM employee;        -- 截取第一个字
SELECT LEFT(user_name, 1) FROM employee;               -- 取左边第一个字
SELECT LTRIM('  hi  ') FROM DUAL;                      -- 去除左边空格
SELECT RTRIM('  hi  ') FROM DUAL;                      -- 去除右边空格
SELECT TRIM('  hi  ') FROM DUAL;                       -- 去除两边空格
```

**练习：以首字母小写的方式显示所有员工的姓名**

```sql
SELECT CONCAT(LCASE(SUBSTRING(user_name,1,1)),SUBSTRING(user_name,2)) FROM employee;
```

## 数学函数

![数学函数](数学函数.png)

```sql
-- 数学运算
SELECT ABS(-3) FROM DUAL;        -- 取绝对值
SELECT MOD(10,3);                -- 取模
SELECT CEILING(3.4);             -- 向上取整
SELECT FLOOR(3.9);               -- 向下取整
SELECT FORMAT(3.568923,3);       -- 保留小数位数
SELECT LEAST(0,1,2);             -- 返回最小值

-- 进制转换
SELECT CONV(10,10,2);            -- 把 10 从十进制转为二进制
SELECT BIN(2) FROM DUAL;         -- 十进制转二进制
SELECT HEX(2) FROM DUAL;         -- 十进制转十六进制

-- 随机数
SELECT RAND() FROM DUAL;         -- 返回 [0,1] 之间的随机数
SELECT RAND(1) FROM DUAL;        -- 返回固定的随机数（指定SEED）
```

## 日期函数

![日期函数](日期函数.png)

**说明：**

- DATE_ADD() 和 DATE_SUB() 中的 type **只能接收一个参数**，如需计算多个时间单位，需要使用函数嵌套实现
- 这四个函数的日期类型可以是 date、datetime 或者 timestamp
- DATEDIFF(date1, date2) **得到的是天数**，而且是 date1 - date2 的天数，因此可以取负数

**补充函数：**

- DATE()：返回日期部分
- TIME()：返回时间部分
- UNIX_TIMESTAMP：返回 1970-01-01 到现在的秒数
- FROM_UNIXTIME()：日期格式化，格式化参数为 `"%Y-%m-%d %H:%i:%s"`

> 在实际开发中，经常使用 int 来保存 unix 时间戳，然后使用 FROM_UNIXTIME() 进行转换，非常实用。

```sql
-- 获取时间
SELECT NOW() FROM DUAL;                 -- 获取当前时间
SELECT CURRENT_DATE() FROM DUAL;        -- 返回当前日期（年月日）
SELECT CURRENT_TIME() FROM DUAL;        -- 返回当前时间（时分秒）
SELECT CURRENT_TIMESTAMP() FROM DUAL;   -- 返回时间戳

-- 指定获取时间部分
SELECT DATE(NOW()) FROM DUAL;           -- 返回日期部分
SELECT TIME(NOW()) FROM DUAL;           -- 返回时间部分

-- 时间戳
SELECT UNIX_TIMESTAMP() FROM DUAL;

-- 日期格式化
SELECT FROM_UNIXTIME(1752751557,"%Y-%m-%d %H:%i:%s") FROM DUAL;

-- 时间计算
SELECT DATEDIFF('2011-11-11','1990-1-1');              -- 计算相差天数
SELECT TIMEDIFF('23:56:23','18:20:56');                -- 计算相差时间
SELECT DATE_ADD(NOW(),INTERVAL 10 DAY);                -- 10天后的时间
SELECT DATE_SUB(NOW(),INTERVAL 10 DAY);                -- 10天前的时间

-- 计算多个时间（嵌套调用）
SELECT
  DATE_ADD(
    DATE_ADD(
      DATE_ADD(
        DATE_ADD(
          DATE_ADD(
            DATE_ADD(NOW(), INTERVAL 2 YEAR),
            INTERVAL 3 MONTH
          ),
          INTERVAL 10 DAY
        ),
        INTERVAL 5 HOUR
      ),
      INTERVAL 30 MINUTE
    ),
    INTERVAL 45 SECOND
  )AS future_time FROM DUAL;

-- 如果能活到100岁，计算还能活多少天（以2006-07-05为例）
SELECT DATEDIFF(DATE_ADD('2006-07-05',INTERVAL 100 YEAR),NOW()) FROM DUAL;
```

## 加密函数

- **MD5(str)**：返回一个长度为 32 的字符串，该种加密方式 **加密后不可逆**
- **PASSWORD(str)**：从原文密码 str 计算并返回密码字符串，通常用于对数据库的用户密码加密

```sql
CREATE TABLE `user`
(
  id CHAR(1),
  `name` CHAR(32),
  `password` CHAR(32)
);

-- 添加数据时密码加密
INSERT INTO `user` (`id`, `name`, `password`)
VALUES ('1', 'jack', MD5('123456'));
```

## 流程控制函数

![流程控制](流程控制.png)

### IF

类似三元运算符：条件为真取第一个结果，否则取第二个结果。

```sql
SELECT IF(TRUE,'jack','jackson') FROM DUAL;
```

### IFNULL

传入两个参数，**谁不为空返回谁**。

```sql
SELECT IFNULL(NULL,'jack');
```

### SELECT CASE

指令：`SELECT CASE WHEN 条件 THEN 执行语句... ELSE 执行语句 END`

```sql
SELECT ename,(SELECT CASE
    WHEN job='CLERK' THEN'职员'
    WHEN job='MANAGER' THEN'经理'
    WHEN job='SALESMAN' THEN'销售人员'
    ELSE job END
)FROM emp;
```

### 判断是否为空

空判断：使用关键字 **IS**，**不要使用 =**。

```sql
SELECT * FROM `user` WHERE `password` IS NULL;
```

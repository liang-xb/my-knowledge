# 存储过程

---

## 基本介绍

存储过程是事先经过编译并存储在数据库中的一段 **SQL 语句的集合**，调用存储过程可以简化应用开发，减少数据在数据库和应用服务器之间的传输，提高数据处理的效率。存储过程思想上就是数据库 **SQL 语言层面的代码封装与重用**。

## 三大特点

1. **封装，复用**：可以把某一业务 SQL 封装在存储过程中，需要时直接调用
2. **可以接收参数，也可以返回数据**：在存储过程中可以传递参数，也可以接收返回值
3. **减少网络交互，效率提升**：如果涉及多条 SQL，封装在存储过程中只需要网络交互一次

## 相关操作

### 创建存储过程

```sql
CREATE PROCEDURE 存储过程名称()
BEGIN
    -- SQL 语句
END;
```

由于 SQL 语句以分号结束，在命令行中创建存储过程时需要重新定义结束符：

```sql
DELIMITER $$

CREATE PROCEDURE p1()
BEGIN
    SELECT * FROM emp;
END$$

DELIMITER ;
```

### 调用存储过程

```sql
CALL p1();
```

### 查看存储过程

```sql
-- 查看指定数据库下的存储过程
SELECT * FROM information_schema.ROUTINES WHERE ROUTINE_SCHEMA = 'db_name';

-- 查看存储过程的创建语句
SHOW CREATE PROCEDURE p1;
```

### 删除存储过程

```sql
DROP PROCEDURE IF EXISTS p1;
```

## 变量

### 系统变量

```sql
-- 查看系统变量
SHOW VARIABLES;
SHOW VARIABLES LIKE 'auto%';

-- 查看指定变量的值
SELECT @@autocommit;
```

### 用户自定义变量

```sql
-- 赋值
SET @name = 'jack';
SET @age := 18;
SELECT COUNT(*) INTO @count FROM emp;

-- 使用
SELECT @name, @age, @count;
```

### 局部变量

```sql
CREATE PROCEDURE p2()
BEGIN
    DECLARE emp_count INT DEFAULT 0;
    SELECT COUNT(*) INTO emp_count FROM emp;
    SELECT emp_count;
END;
```

## 参数

```sql
-- IN：输入参数
CREATE PROCEDURE p3(IN dept_id INT)
BEGIN
    SELECT * FROM emp WHERE dept_id = dept_id_param;
END;

-- OUT：输出参数
CREATE PROCEDURE p4(OUT total INT)
BEGIN
    SELECT COUNT(*) INTO total FROM emp;
END;

-- INOUT：既是输入也是输出
CREATE PROCEDURE p5(INOUT val INT)
BEGIN
    SET val = val * 2;
END;
```

## 流程控制

### IF

```sql
CREATE PROCEDURE p6(IN score INT)
BEGIN
    IF score >= 90 THEN
        SELECT '优秀';
    ELSEIF score >= 60 THEN
        SELECT '及格';
    ELSE
        SELECT '不及格';
    END IF;
END;
```

### CASE

```sql
CREATE PROCEDURE p7(IN month INT)
BEGIN
    CASE
        WHEN month >= 1 AND month <= 3 THEN SELECT '第一季度';
        WHEN month >= 4 AND month <= 6 THEN SELECT '第二季度';
        ELSE SELECT '其他季度';
    END CASE;
END;
```

### LOOP / WHILE / REPEAT

```sql
-- WHILE 循环
CREATE PROCEDURE p8(IN n INT)
BEGIN
    DECLARE i INT DEFAULT 0;
    DECLARE total INT DEFAULT 0;
    WHILE i <= n DO
        SET total := total + i;
        SET i := i + 1;
    END WHILE;
    SELECT total;
END;

-- REPEAT 循环（先执行后判断）
CREATE PROCEDURE p9(IN n INT)
BEGIN
    DECLARE i INT DEFAULT 0;
    REPEAT
        SET i := i + 1;
    UNTIL i >= n END REPEAT;
    SELECT i;
END;

-- LOOP 循环（需要配合 LEAVE）
CREATE PROCEDURE p10(IN n INT)
BEGIN
    DECLARE i INT DEFAULT 0;
    myloop: LOOP
        SET i := i + 1;
        IF i >= n THEN
            LEAVE myloop;
        END IF;
    END LOOP;
    SELECT i;
END;
```

## 游标

游标是用来存储查询结果集的数据类型，在存储过程和函数中可以使用游标对结果集进行循环处理：

```sql
CREATE PROCEDURE p11()
BEGIN
    DECLARE e_name VARCHAR(50);
    DECLARE e_salary DECIMAL(10,2);
    DECLARE done INT DEFAULT 0;

    -- 声明游标
    DECLARE emp_cursor CURSOR FOR SELECT name, salary FROM emp;

    -- 声明退出条件
    DECLARE CONTINUE HANDLER FOR NOT FOUND SET done = 1;

    OPEN emp_cursor;

    read_loop: LOOP
        FETCH emp_cursor INTO e_name, e_salary;
        IF done THEN
            LEAVE read_loop;
        END IF;
        -- 处理每行数据
        SELECT e_name, e_salary;
    END LOOP;

    CLOSE emp_cursor;
END;
```

## 存储函数

存储函数是有返回值的存储过程，参数只能是 IN 类型：

```sql
CREATE FUNCTION func1(n INT)
RETURNS INT
DETERMINISTIC
BEGIN
    DECLARE result INT DEFAULT 0;
    -- 计算 1 到 n 的和
    SELECT SUM(num) INTO result FROM (
        SELECT @rownum := @rownum + 1 AS num
        FROM (SELECT 0 UNION SELECT 1 UNION SELECT 2 UNION SELECT 3) a,
             (SELECT 0 UNION SELECT 1 UNION SELECT 2 UNION SELECT 3) b,
             (SELECT @rownum := 0) r
    ) tmp WHERE num <= n;
    RETURN result;
END;

-- 调用
SELECT func1(10);
```

## 用户管理

### 用户表

![用户表](用户表.png)

![用户表字段说明](用户表字段说明.png)

### 查询用户

```sql
-- 查询所有用户
SELECT * FROM mysql.user;

-- 查询当前用户
SELECT USER();
```

### 创建用户

```sql
CREATE USER '用户名'@'主机名' IDENTIFIED BY '密码';
```

主机名可以是 `localhost`（本机）或 `%`（任意主机）。

```sql
-- 创建只能本机访问的用户
CREATE USER 'jack'@'localhost' IDENTIFIED BY '123456';

-- 创建任意主机可访问的用户
CREATE USER 'jack'@'%' IDENTIFIED BY '123456';
```

### 修改用户密码

```sql
ALTER USER '用户名'@'主机名' IDENTIFIED BY '新密码';
```

### 删除用户

```sql
DROP USER '用户名'@'主机名';
```

## 权限管理

### 常用权限

| 权限 | 说明 |
| ---- | ---- |
| ALL / ALL PRIVILEGES | 所有权限 |
| SELECT / INSERT / UPDATE / DELETE | 增删改查 |
| CREATE / ALTER / DROP | 数据库/表操作 |
| INDEX | 索引操作 |
| REFERENCES | 外键权限 |

### 授予权限

```sql
GRANT 权限列表 ON 数据库.表 TO '用户名'@'主机名';

-- 授予所有数据库的所有权限
GRANT ALL ON *.* TO 'jack'@'%';

-- 授予指定数据库的所有权限
GRANT ALL ON mydb.* TO 'jack'@'%';

-- 授予指定表的查询和插入权限
GRANT SELECT, INSERT ON mydb.emp TO 'jack'@'%';
```

### 查看权限

```sql
SHOW GRANTS FOR '用户名'@'主机名';
```

### 撤销权限

```sql
REVOKE 权限列表 ON 数据库.表 FROM '用户名'@'主机名';
```

### 刷新权限

```sql
FLUSH PRIVILEGES;
```

## 系统变量

```sql
-- 查看所有系统变量
SHOW VARIABLES;

-- 模糊查询
SHOW VARIABLES LIKE 'auto%';

-- 查看指定变量
SELECT @@autocommit;

-- 设置会话级别变量
SET SESSION autocommit = 1;

-- 设置全局级别变量
SET GLOBAL autocommit = 1;
```

## 慢查询日志

慢查询日志记录了所有执行时间超过指定参数（long_query_time，默认 10 秒）的所有 SQL 语句的日志。

![慢查询日志](慢查询日志.png)

```sql
-- 查看慢查询日志是否开启
SHOW VARIABLES LIKE 'slow_query_log';

-- 开启慢查询日志
SET GLOBAL slow_query_log = 'ON';

-- 查看慢查询阈值
SHOW VARIABLES LIKE 'long_query_time';

-- 设置慢查询阈值
SET GLOBAL long_query_time = 2;
```

## SHOW PROFILE

SHOW PROFILE 可以查看 SQL 语句在各个阶段的耗时情况，用于性能分析：

```sql
-- 查看 profiling 是否开启
SELECT @@profiling;

-- 开启 profiling
SET profiling = 1;

-- 执行查询
SELECT * FROM emp;

-- 查看所有查询的 profile
SHOW PROFILES;

-- 查看指定查询的详细 profile
SHOW PROFILE FOR QUERY 1;

-- 查看 CPU 使用情况
SHOW PROFILE CPU FOR QUERY 1;
```

## MySQL 管理工具

- **mysql**：命令行客户端工具
- **mysqladmin**：管理工具，如关闭服务、查看状态等
- **mysqlbinlog**：二进制日志查看工具
- **mysqlcheck**：表维护工具，检查、修复、优化表
- **mysqldump**：数据备份工具
- **mysqlimport**：数据导入工具
- **mysqlshow**：快速查看数据库、表、列信息

# Lua 语法入门

---

## 基本介绍

- 官网：https://www.lua.org/
- Nginx 编程需要用到 Lua 语言，因此必须先入门 Lua 的基本语法
- Lua 是一种轻量小巧的脚本语言，用标准 C 语言编写并以源代码形式开放，其设计目的是为了嵌入应用程序中，从而为应用程序提供灵活的扩展和定制功能
- Lua 经常嵌入到 C 语言开发的程序中，例如游戏开发、游戏插件等。Nginx 本身也是 C 语言开发，因此也允许基于 Lua 做拓展

在 Linux 下，使用 `lua` 命令即可进入 Lua 控制台：

```lua
print("Hello World")
```

## 变量

```lua
-- 全局变量
a = 10

-- 局部变量（推荐使用）
local b = 20

-- 同时赋值
local x, y = 1, 2

-- nil 表示空
local c = nil
```

## 数据类型

Lua 有 8 种基本数据类型：

| 类型 | 说明 |
| ---- | ---- |
| nil | 无效值，表示空 |
| boolean | true / false |
| number | 数字（整数或浮点数） |
| string | 字符串 |
| function | 函数 |
| userdata | 用户自定义数据 |
| thread | 线程 |
| table | 表（类似数组/字典） |

```lua
local str = "hello"        -- 字符串
local num = 123            -- 数字
local flag = true          -- 布尔
local arr = {1, 2, 3}      -- 数组
local map = {name="jack", age=18}  -- 字典
```

## 循环

```lua
-- while 循环
local i = 0
while i < 10 do
    print(i)
    i = i + 1
end

-- for 循环
for i = 1, 10 do
    print(i)
end

-- 遍历数组
local arr = {1, 2, 3, 4, 5}
for i, v in ipairs(arr) do
    print(i, v)
end
```

## 条件判断

```lua
local age = 18

if age < 18 then
    print("未成年")
elseif age < 60 then
    print("成年")
else
    print("老年")
end
```

## 函数

```lua
-- 定义函数
local function add(a, b)
    return a + b
end

-- 调用函数
local result = add(10, 20)
print(result)  -- 30
```

## 在 Redis 中使用 Lua

Redis 支持通过 EVAL 命令执行 Lua 脚本，脚本中的写操作具有 **原子性**。

```bash
# EVAL script numkeys key [key ...] arg [arg ...]
EVAL "return redis.call('set', KEYS[1], ARGV[1])" 1 name jack
```

### 示例：库存扣减脚本

```lua
-- 判断库存是否充足，充足则扣减
local voucherId = ARGV[1]
local userId = ARGV[2]

-- 库存 key
local stockKey = 'seckill:stock:' .. voucherId
-- 订单 key
local orderKey = 'seckill:order:' .. voucherId

-- 判断库存是否充足
if tonumber(redis.call('get', stockKey)) <= 0 then
    return 1  -- 库存不足
end

-- 判断是否重复下单
if redis.call('sismember', orderKey, userId) == 1 then
    return 2  -- 重复下单
end

-- 扣减库存
redis.call('incrby', stockKey, -1)
-- 记录用户
redis.call('sadd', orderKey, userId)
return 0  -- 成功
```

### Java 中执行 Lua 脚本

```java
    // 1. 加载 Lua 脚本
    DefaultRedisScript<Long> script = new DefaultRedisScript<>();
    script.setLocation(new ClassPathResource("seckill.lua"));
    script.setResultType(Long.class);

    // 2. 执行脚本
    Long result = stringRedisTemplate.execute(script,
            Collections.emptyList(),
            voucherId.toString(), userId.toString());

    // 3. 判断结果

        return Result.fail("库存不足");
    } else if (result == 2) {
        return Result.fail("不能重复下单");
    }

    // ...

    return Result.ok(0);
}
```

# Spring Cache 框架

---

## 基本介绍

Spring Cache 是一个 **缓存框架**，只需要简单地加一个 **注解**，就能实现缓存功能。

Spring Cache 提供了一层抽象，底层可以切换不同的缓存实现，例如：EHCache、Caffeine、Redis（常用）。

## Maven 依赖坐标

```xml
<dependency>
    <groupId>org.springframework.boot</groupId>
    <artifactId>spring-boot-starter-cache</artifactId>
</dependency>
```

## 常用注解

Spring Cache **注解生效的前提**：在启动类上使用 `@EnableCaching` 开启缓存支持。

![Spring Cache注解](21.png)

## 代码示例

### @EnableCaching

在启动类上使用 `@EnableCaching` 开启缓存支持：

```java
@SpringBootApplication
@EnableCaching
public class Application {
    public static void main(String[] args) {
        SpringApplication.run(Application.class, args);
    }
}
```

### @Cacheable

在方法上添加 `@Cacheable` 注解，方法返回结果会被缓存。下次调用时，先从缓存中查找，缓存命中则直接返回，不执行方法体。

```java
@Service
public class UserServiceImpl implements UserService {

    @Override
    @Cacheable(cacheNames = "user", key = "#id")
    public User getById(Long id) {
        return userMapper.selectById(id);
    }
}
```

### @CacheEvict

用于清除缓存，常用于更新或删除操作：

```java
@Override
@CacheEvict(cacheNames = "user", key = "#user.id")
public void update(User user) {
    userMapper.updateById(user);
}

@Override
@CacheEvict(cacheNames = "user", key = "#id")
public void deleteById(Long id) {
    userMapper.deleteById(id);
}
```

### @CachePut

更新缓存而不影响方法执行，方法总会执行并将返回值放入缓存：

```java
@Override
@CachePut(cacheNames = "user", key = "#user.id")
public User updateAndCache(User user) {
    userMapper.updateById(user);
    return user;
}
```

## 常用属性

| 属性 | 说明 |
| ---- | ---- |
| cacheNames / value | 指定缓存名称 |
| key | 缓存数据的 key，支持 SpEL 表达式 |
| condition | 缓存条件，满足条件才缓存 |
| unless | 不缓存条件，满足条件则不缓存 |

```java
@Cacheable(
    cacheNames = "user",
    key = "#id",
    condition = "#id > 10",           // id > 10 时才缓存
    unless = "#result == null"         // 结果为 null 不缓存
)
public User getById(Long id) {
    return userMapper.selectById(id);
}
```

# AOP

---

## 基本介绍

AOP（Aspect Oriented Programming，**面向切面编程**），本质是**面向特定方法编程**。

### 为什么需要 AOP

项目中某些业务方法需要统计执行耗时。传统做法是在每个方法前后加入计时代码：

```java
public List<Dept> list() {
    long beginTime = System.currentTimeMillis();
    List<Dept> deptList = deptMapper.list();
    long endTime = System.currentTimeMillis();
    log.info("执行耗时: {} ms", endTime - beginTime);
    return deptList;
}
// 每个方法都要重复这些代码...
```

而使用 AOP 只需定义一段代码：

```java
@Slf4j
@Aspect
@Component
public class RecordTimeAspect {
    @Around("execution(* com.itheima.service.*.*(..))")
    public Object recordTime(ProceedingJoinPoint pjp) throws Throwable {
        long beginTime = System.currentTimeMillis();
        Object result = pjp.proceed();
        long endTime = System.currentTimeMillis();
        log.info("执行耗时:{}ms", endTime - beginTime);
        return result;
    }
}
```

### AOP 优势

1. **减少重复代码**：重复逻辑抽取到 AOP 程序中
2. **代码无侵入**：不修改任何业务代码
3. **提高开发效率，维护方便**

### 常见应用场景

- 记录操作日志
- 权限控制
- 事务管理（`@Transactional` 底层就是 AOP）

## AOP 实现

### 引入依赖

```xml
<dependency>
    <groupId>org.springframework.boot</groupId>
    <artifactId>spring-boot-starter-aop</artifactId>
</dependency>
```

### 入门程序

```java
@Component
@Aspect      // 标记为切面类
@Slf4j
public class RecordTimeAspect {
    @Around("execution(* com.itheima.service.impl.DeptServiceImpl.*(..))")
    public Object recordTime(ProceedingJoinPoint pjp) throws Throwable {
        long begin = System.currentTimeMillis();
        Object result = pjp.proceed();   // 执行原始方法
        long end = System.currentTimeMillis();
        log.info("方法执行耗时: {}毫秒", end - begin);
        return result;
    }
}
```

### 底层实现

Spring AOP 底层基于**动态代理**：运行时为目标对象生成代理对象，在代理对象中对原始方法进行功能增强。

## 核心概念

| 概念 | 说明 |
| ---- | ---- |
| **连接点 (JoinPoint)** | 可以被 AOP 控制的方法，封装了方法执行时的相关信息 |
| **通知 (Advice)** | 抽取出来的共性功能（重复逻辑），最终体现为一个方法 |
| **切入点 (PointCut)** | 匹配连接点的条件，通过**切入点表达式**来定义 |
| **切面 (Aspect)** | 通知 + 切入点的结合，描述"对哪些方法、在何时、做什么" |
| **目标对象 (Target)** | 通知所应用的对象 |

### JoinPoint 常用方法

| 通知类型 | 连接点参数类型 |
| -------- | -------------- |
| `@Around` | 只能使用 `ProceedingJoinPoint`（子类） |
| 其他四种 | 只能使用 `JoinPoint`（父类） |

```java
// @Around 通知
@Around("execution(* com.itheima.service.DeptService.*(..))")
public Object around(ProceedingJoinPoint joinPoint) throws Throwable {
    String className = joinPoint.getTarget().getClass().getName();  // 目标类名
    String methodName = joinPoint.getSignature().getName();          // 目标方法名
    Object[] args = joinPoint.getArgs();                            // 目标方法参数
    Object res = joinPoint.proceed();                               // 执行原始方法
    return res;
}

// @Before 通知
@Before("execution(* com.itheima.service.DeptService.*(..))")
public void before(JoinPoint joinPoint) {
    String className = joinPoint.getTarget().getClass().getName();
    String methodName = joinPoint.getSignature().getName();
    Object[] args = joinPoint.getArgs();
}
```

## 通知

### 通知类型

| 注解 | 说明 |
| ---- | ---- |
| `@Before` | 前置通知，在目标方法执行前执行 |
| `@Around` | 环绕通知，包裹目标方法，可控制方法是否执行 |
| `@After` | 后置通知，在目标方法执行后执行（无论是否异常） |
| `@AfterReturning` | 返回后通知，正常执行完成后执行 |
| `@AfterThrowing` | 异常通知，异常时执行 |

::: tip 注意
- `@Around` 需要手动调用 `pjp.proceed()` 执行原始方法
- `@Around` 返回值必须为 `Object`，接收原始方法返回值
:::

```java
@Slf4j
@Component
@Aspect
public class MyAspect {
    @Pointcut("execution(* com.itheima.service.*.*(..))")
    private void pt() {}

    @Before("pt()")
    public void before(JoinPoint joinPoint) { log.info("before ..."); }

    @Around("pt()")
    public Object around(ProceedingJoinPoint joinPoint) throws Throwable {
        log.info("around before ...");
        Object result = joinPoint.proceed();
        log.info("around after ...");
        return result;
    }

    @After("pt()")
    public void after(JoinPoint joinPoint) { log.info("after ..."); }

    @AfterReturning("pt()")
    public void afterReturning(JoinPoint joinPoint) { log.info("afterReturning ..."); }

    @AfterThrowing("pt()")
    public void afterThrowing(JoinPoint joinPoint) { log.info("afterThrowing ..."); }
}
```

### @PointCut 抽取

当多个通知的切入点表达式相同时，可用 `@PointCut` 抽取，避免重复。

> 切入点方法用 `private` 修饰时仅限当前切面类引用；`public` 可被外部切面类引用：`com.itheima.aspect.MyAspect.pt()`

### 通知顺序

默认按切面类的**类名字母排序**：
- 目标方法**前**：字母靠前的**先**执行
- 目标方法**后**：字母靠前的**后**执行

使用 `@Order` 注解可精确控制顺序：

```java
@Aspect
@Component
@Order(2)  // 数字越小，前置先执行、后置后执行
public class MyAspect { ... }
```

## 切入点表达式

### execution

根据方法签名匹配：

```
execution(访问修饰符? 返回值 包名.类名.方法名(参数) throws 异常?)
```

**通配符：**

| 符号 | 说明 |
| ---- | ---- |
| `*` | 单个独立任意符号（匹配任意返回值、包名、类名、方法名、一个任意类型参数） |
| `..` | 多个连续任意符号（匹配任意层级包，或任意类型、任意个数参数） |

```java
// 示例（由精确到宽泛）
execution(void com.itheima.service.impl.DeptServiceImpl.delete(java.lang.Integer))
execution(* com.itheima.service.impl.DeptServiceImpl.delete(java.lang.Integer))
execution(* com.itheima.*.*.DeptServiceImpl.delete(java.lang.Integer))
execution(* com..DeptServiceImpl.delete(java.lang.Integer))
execution(* com..*.delete(java.lang.Integer))
execution(* com..*.*(..))
```

可组合使用 `&&`、`||`、`!`：

```java
execution(* com.itheima.service.DeptService.list(..)) ||
execution(* com.itheima.service.DeptService.delete(..))
```

**书写建议：**
- 方法名尽量规范（如 `findXxx`、`updateXxx`），方便快速匹配
- 尽量基于接口描述，而非实现类
- 在满足需求的前提下，缩小切入点范围（包名少用 `..`，多用 `*`）

### @annotation

根据注解匹配，适合匹配多个不规则方法：

```java
// 1. 自定义注解
@Target(ElementType.METHOD)
@Retention(RetentionPolicy.RUNTIME)
public @interface LogOperation {}

// 2. 切面类
@Before("@annotation(com.itheima.anno.LogOperation)")
public void before() { log.info("before ..."); }

// 3. 业务类使用
@Override
@LogOperation
public List<Dept> list() { ... }
```

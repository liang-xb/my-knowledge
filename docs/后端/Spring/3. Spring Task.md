# Spring Task

---

## 基本介绍

Spring Task 是 Spring 框架提供的**定时任务框架**，可按照约定的时间自动执行 Java 代码。

**应用场景：** 信用卡还款提醒、处理未支付订单、入职纪念日通知、数据定时同步等。

## cron 表达式

cron 表达式是一个字符串，用于**定义任务触发的时间**。在线生成器：<https://cron.qqe2.com>

### 语法规则

由 6 或 7 个域组成，空格分隔：

```
秒 分 时 日 月 周 [年(可选)]
```

> 一般**日和周不同时设置**，其中一个设置，另一个用 `?` 表示。

### 通配符

| 符号 | 说明 | 示例 |
| ---- | ---- | ---- |
| `*` | 所有值 | `* * * * * ?` 每秒 |
| `?` | 不指定值（用于日/周互斥） | — |
| `-` | 指定范围 | `5-15` |
| `,` | 附加可能值 | `10,14,16` |
| `/` | 步进（前为起始，后为间隔） | `0/5` 每 5 个单位 |

### 常用示例

| 表达式 | 说明 |
| ------ | ---- |
| `*/5 * * * * ?` | 每隔 5 秒 |
| `0 */1 * * * ?` | 每隔 1 分钟 |
| `0 0 5-15 * * ?` | 每天 5-15 点整点触发 |
| `0 0/3 * * * ?` | 每 3 分钟触发一次 |
| `0 0/30 9-17 * * ?` | 朝九晚五每半小时 |
| `0 0 10,14,16 * * ?` | 每天 10 点、14 点、16 点 |
| `0 0 12 ? * 1` | 每周一中午 12 点 |

## 代码实现

> `spring-boot-starter` 已包含 Spring Task 依赖，无需额外引入。

### @EnableScheduling

启动类添加 `@EnableScheduling` 开启任务调度：

```java
@SpringBootApplication
@EnableScheduling
public class SkyApplication {
    public static void main(String[] args) {
        SpringApplication.run(SkyApplication.class, args);
    }
}
```

### @Scheduled

在方法上添加 `@Scheduled` 注解并指定 cron 表达式：

```java
@Component
@Slf4j
public class MyTask {
    @Scheduled(cron = "0/5 * * * * ?")  // 每隔 5 秒触发
    public void executeTask() {
        log.info("定时任务执行：{}", new Date());
    }
}
```

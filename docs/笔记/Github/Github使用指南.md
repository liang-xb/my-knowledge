# <center>GitHub 使用技巧</center>

---

## 一、常见名词

- **repository**：仓库
- **fork**：复刻
- **star**：收藏
- **issue**：在一个仓库创建话题讨论
- **pull request（PR）**：请求仓库主人拉取你的代码合并到主分支
- **README.md**：项目文档
- **.gitignore**：忽略文件配置
- **license**：开源许可证
- **releases**：发布的版本，可直接下载

## 二、搜索技巧

- 高级搜索：搜索结果页左下角 **advanced search** 可附加筛选条件
- 常用搜索套路：
  - 找百科大全：`awesome xxx`
  - 找示例：`xxx sample`
  - 找项目脚手架：`xxx starter` / `xxx boilerplate`
  - 找教程：`xxx tutorial`

## 三、便捷操作

1. 按下 `t` 键 — 对仓库文件进行搜索，快速跳转
2. 按下 `l` 键 — 跳转到指定行号
3. 按下 `b` 键 — 查看文件修改记录（blame）
4. 按下 `.` 键 — 使用网页版 VS Code 打开项目
5. 项目地址前加 `gitpod.io/#/` — 在线运行项目

## 四、发现优质项目

1. [Hello GitHub](https://hellogithub.com/) — 中文社区，推荐有意思的开源项目
2. [GitHub Trending](https://github.com/trending) — 每日热门仓库
3. [LibHunt](https://www.libhunt.com/) — 开源项目分类收录站
4. [searchcode](https://searchcode.com/) — 按代码片段搜索，可筛选语言和平台
5. [codelf](https://unbug.github.io/codelf/) — 变量命名工具

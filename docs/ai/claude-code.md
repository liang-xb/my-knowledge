# Claude Code

Claude Code 是 Anthropic 推出的 AI 编程助手 CLI 工具。

## 什么是 Claude Code

Claude Code 是一个命令行 AI 编程助手，直接在你的终端中运行，理解整个代码库上下文，帮助你编写、调试和重构代码。

## 核心功能

- **代码生成**：根据描述生成代码
- **代码审查**：分析代码质量并给出建议
- **Bug 修复**：定位和修复 Bug
- **重构**：优化代码结构和可读性
- **测试生成**：自动生成单元测试
- **文档编写**：生成注释和文档

## 基本使用

```bash
# 安装
npm install -g @anthropic-ai/claude-code

# 启动
claude

# 在 Claude Code 中
> 帮我写一个 Spring Boot Controller
> 这个函数的性能有什么问题
> 帮这个类写单元测试
```

## 常用工作流

### 1. 理解陌生代码

```
> 这个项目是做什么的？帮我梳理一下整体架构
> 这个 Service 类的主要逻辑是什么
```

### 2. 添加新功能

```
> 在 UserController 中添加一个根据用户名模糊查询的接口
> 需要返回分页结果
```

### 3. 代码审查

```
> 审查这个 PR 的代码，有什么潜在问题
> 这个 SQL 写法安全吗，有没有注入风险
```

## 使用技巧

1. **明确上下文**：告诉它你正在做什么
2. **分步骤**：复杂任务拆分成小步骤
3. **提供示例**：说明你期望的风格
4. **迭代反馈**：基于结果不断调整

## 安装条件

- Node.js 18+
- Git（用于版本控制感知）
- 需要 Anthropic API Key

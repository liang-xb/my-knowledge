# 算法总结

算法学习的核心要点和方法总结。

## 核心数据结构

| 数据结构 | 特点 | 适用场景 |
|----------|------|----------|
| 数组 | 随机访问 O(1) | 需要快速查询 |
| 链表 | 插入删除 O(1) | 频繁增删 |
| 栈 | 后进先出 | 括号匹配、表达式求值 |
| 队列 | 先进先出 | BFS、任务调度 |
| 哈希表 | 查找 O(1) | 去重、计数、映射 |
| 堆 | 最值 O(1) | TopK、优先队列 |
| 树 | 层次结构 | 文件系统、组织架构 |
| 图 | 网络结构 | 社交网络、路径规划 |

## 算法思想对比

| 思想 | 核心 | 典型问题 |
|------|------|----------|
| 双指针 | 两个指针移动 | 两数之和、链表环 |
| 滑动窗口 | 窗口扩大缩小 | 最长无重复子串 |
| 二分查找 | 不断缩小范围 | 搜索插入位置 |
| 分治 | 分解合并 | 归并排序 |
| 回溯 | 试错回退 | 全排列、N 皇后 |
| 贪心 | 每步最优 | 跳跃游戏 |
| 动态规划 | 状态转移 | 背包问题 |

## 时间复杂度优化思路

1. **暴力解法** → 找重复计算 → 记忆化 → DP
2. **O(n²)** → 考虑双指针 / 滑动窗口 → O(n)
3. **有序数组** → 二分查找 → O(log n)
4. **需要最值** → 堆 → O(n log k)
5. **需要快速查找** → 哈希表 → O(1)

## 刷题三遍法

1. **第一遍**：理解题目，写出解法
2. **第二遍**：隔天重写，优化代码
3. **第三遍**：一周后再写，总结模板

## 面试技巧

- 先确认题意，说思路再写代码
- 注意边界条件和异常输入
- 分析时间和空间复杂度
- 写完后用测试用例手动跑一遍

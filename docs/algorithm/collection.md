# 算法集锦

收集常用算法和数据结构的核心笔记。

## 时间复杂度速查

| 复杂度 | 示例 | 说明 |
|--------|------|------|
| O(1) | 数组按下标访问 | 最快 |
| O(log n) | 二分查找 | 每步减半 |
| O(n) | 遍历数组 | 线性 |
| O(n log n) | 归并排序 | 排序算法下限 |
| O(n²) | 冒泡排序 | 两重循环 |

## 常用算法思想

- **双指针** — 快慢指针、对撞指针，处理数组/链表
- **滑动窗口** — 子数组/子串问题
- **二分查找** — 有序数组快速定位
- **递归/回溯** — 排列组合、子集问题
- **动态规划** — 最优子结构问题
- **贪心** — 局部最优推全局最优

## 排序算法对比

| 算法 | 平均 | 空间 | 稳定 |
|------|------|------|------|
| 冒泡 | O(n²) | O(1) | ✓ |
| 选择 | O(n²) | O(1) | ✗ |
| 插入 | O(n²) | O(1) | ✓ |
| 归并 | O(n log n) | O(n) | ✓ |
| 快速 | O(n log n) | O(log n) | ✗ |

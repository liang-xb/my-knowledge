# 左程云算法

左程云（左神）的算法课程体系，专注于大厂面试算法。

## 课程体系

### 基础班
- 时间复杂度分析
- 对数器
- 冒泡、选择、插入排序
- 归并排序与快速排序
- 堆排序
- 二分查找

### 进阶班
- KMP 算法
- Manacher 算法
- 滑动窗口
- 单调栈
- 树形 DP
- 并查集

### 高频班
- 链表高频题
- 二叉树高频题
- 动态规划高频题
- 贪心高频题
- 图论高频题

## 学习特点

- **对数器**：强调用对数器验证算法正确性
- **coding 能力**：要求能白板手写核心算法
- **复杂度敏感**：每道题都要分析时空复杂度

## 核心思想

| 思想 | 应用场景 |
|------|----------|
| 对数器 | 验证算法正确性 |
| 贪心 | 局部最优推全局最优 |
| 递归到动态规划 | 优化暴力递归 |
| 预处理 | 用空间换时间 |

## 推荐刷题顺序

1. 基础排序算法（必须能手写）
2. 二分查找及其变种
3. 链表经典题
4. 二叉树遍历与递归
5. 动态规划经典模型
6. 贪心算法
7. 图的基本算法

# 代码随想录 — 基本介绍

代码随想录是程序员Carl 出品的算法学习体系，以「循序渐进、通俗易懂」著称。

## 课程特色

- **视频 + 文字**：每道题都有详细题解和视频讲解
- **由浅入深**：从数组入门到动态规划进阶
- **分类刷题**：按算法专题系统刷题
- **提供模板**：常用算法提供代码模板

## 主要内容

### 核心章节

1. 数组
2. 链表

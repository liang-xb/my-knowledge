# 算法训练营

代码随想录算法训练营的学习计划和安排。

## 学习周期

训练营通常为期 **60 天**，每天 1-3 道题目。

## 阶段安排

### 第一阶段（第 1-15 天）基础
- 数组：二分查找、移除元素、有序数组的平方
- 链表：反转链表、环形链表、链表相交
- 哈希表：字母异位词、两数之和、三数之和
- 字符串：反转字符串、替换空格

### 第二阶段（第 16-30 天）进阶
- 栈与队列：有效括号、逆波兰表达式、滑动窗口最大值
- 二叉树：遍历方式、层序遍历、对称二叉树
- 回溯：组合问题、分割问题、子集问题、全排列

### 第三阶段（第 31-45 天）提高
- 贪心：分发饼干、摆动序列、跳跃游戏
- 动态规划：爬楼梯、不同路径、整数拆分

### 第四阶段（第 46-60 天）冲刺
- 背包问题
- 打家劫舍系列
- 股票问题系列
- 子序列问题

## 每日学习流程

1. 阅读题目并独立思考（15-30 分钟）
2. 看题解视频理解思路
3. 手写代码并调试
4. 总结该题涉及的知识点
5. 隔天复习重写

## 注意事项

- 不要只看不写，每道题必须手写
- 遇到困难不要死磕，及时看题解
- 做好笔记，记录常见模板
- 定期回顾错题

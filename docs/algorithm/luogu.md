# 洛谷

洛谷（luogu.com.cn）是国内知名的算法竞赛在线评测平台。

## 平台特点

- 海量题目库，涵盖各级别难度
- 支持 C/C++、Java、Python 等多种语言
- 有题解区和讨论区，方便学习交流
- 提供比赛、题单、团队功能

## 题单推荐

### 官方题单
- 【入门】洛谷的第一个任务
- 【入门】顺序结构
- 【入门】分支结构
- 【入门】循环结构
- 【基础】数组
- 【基础】字符串
- 【基础】函数与递归
- 【基础】排序

### 能力提升
- 【提高】二分查找与二分答案
- 【提高】深度优先搜索
- 【提高】广度优先搜索
- 【提高】动态规划基础
- 【提高】简单数论

## 常用操作

```
// 提交代码注意事项
```

## 刷题建议

1. 从入门题单开始，逐步提升
2. 每道题先独立思考，再看题解
3. 注意代码风格和注释习惯
4. 参加洛谷月赛检验水平

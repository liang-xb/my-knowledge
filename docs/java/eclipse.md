# Eclipse

Eclipse 是另一款流行的 Java IDE，免费开源。

## 下载安装

从 [eclipse.org](https://www.eclipse.org/downloads/) 下载 **Eclipse IDE for Java Developers**。

## 基本操作

| 操作 | 说明 |
|------|------|
| 创建工作区 | 启动时选择一个目录作为 workspace |
| 创建项目 | File → New → Java Project |
| 创建类 | 右键 src → New → Class |
| 运行 | 右键类 → Run As → Java Application |

## Eclipse vs IDEA

| 特性 | Eclipse | IDEA |
|------|---------|------|
| 学习成本 | 中等 | 低 |
| 性能 | 较快 | 需要较多内存 |
| 代码提示 | 一般 | 智能 |
| 企业使用 | 老项目多 | 主流选择 |
| 价格 | 免费 | 社区版免费 |

## 常用快捷键

| 快捷键 | 功能 |
|--------|------|
| `Alt + /` | 代码补全 |
| `Ctrl + 1` | 快速修复 |
| `Ctrl + Shift + O` | 自动导包 |
| `Ctrl + Shift + F` | 格式化代码 |
| `Ctrl + F11` | 运行 |
| `F11` | 调试 |
| `Ctrl + D` | 删除行 |
| `Alt + ↑/↓` | 移动行 |

## 工作区配置

- **编码**：Window → Preferences → General → Workspace → UTF-8
- **字体**：Window → Preferences → General → Appearance → Colors and Fonts
- **JDK**：Window → Preferences → Java → Installed JREs

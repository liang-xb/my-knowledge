# IDEA 快捷键

IntelliJ IDEA 常用快捷键速查表。

## 编辑

| 快捷键 | 功能 |
|--------|------|
| `Ctrl + Space` | 代码补全 |
| `Ctrl + Shift + Enter` | 补全语句结尾 |
| `Ctrl + D` | 复制行 |
| `Ctrl + Y` | 删除行 |
| `Ctrl + /` | 行注释 |
| `Ctrl + Shift + /` | 块注释 |
| `Ctrl + Alt + L` | 格式化代码 |
| `Ctrl + Alt + O` | 优化导入 |
| `Tab` | 缩进 |
| `Shift + Tab` | 反缩进 |

## 查找与替换

| 快捷键 | 功能 |
|--------|------|
| `Ctrl + F` | 当前文件查找 |
| `Ctrl + R` | 当前文件替换 |
| `Ctrl + Shift + F` | 全局查找 |
| `Ctrl + Shift + R` | 全局替换 |
| `Double Shift` | 全局搜索 |

## 导航

| 快捷键 | 功能 |
|--------|------|
| `Ctrl + N` | 查找类 |
| `Ctrl + Shift + N` | 查找文件 |
| `Ctrl + E` | 最近文件 |
| `Ctrl + B` | 跳转到定义 |
| `Alt + ←/→` | 前进/后退 |

## 代码生成

| 快捷键 | 功能 |
|--------|------|
| `Alt + Insert` | 生成代码（构造器、Getter/Setter 等） |
| `Ctrl + O` | 重写方法 |
| `Ctrl + I` | 实现方法 |

## 常用

| 快捷键 | 功能 |
|--------|------|
| `Ctrl + Shift + F10` | 运行 |
| `Shift + F9` | 调试 |
| `Shift + F6` | 重命名 |
| `Ctrl + W` | 递进式选择 |

## 后缀补全

```
变量名.for   →  for (xx : 变量) { }
变量名.sout  →  System.out.println(变量)
变量名.nn    →  if (变量 != null) { }
变量名.return → return 变量;
```

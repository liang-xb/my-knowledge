# 优质开源项目

记录值得收藏和学习的开源项目。

## 综合推荐平台

- **[Hello Github](https://hellogithub.com/)** — 中文社区，每月精选有意思的开源项目
- **[GitHub Trending](https://github.com/trending)** — GitHub 每日热门仓库
- **[GitStar Ranking](https://gitstar-ranking.com/)** — 按 star 数排名的仓库榜单
- **[LibHunt](https://www.libhunt.com/)** — 按分类浏览开源项目，功能强大
- **[SearchCode](https://searchcode.com/)** — 根据代码片段搜索开源项目

## Java 项目

- **[JeecgBoot](https://github.com/jeecgboot/JeecgBoot)** — 低代码开发平台
- **[RuoYi](https://github.com/yangzongzhian/RuoYi)** — 若依后台管理系统
- **[Mall](https://github.com/macrozheng/mall)** — 电商系统实战项目
- **[Spring Boot Demo](https://github.com/xkcoding/spring-boot-demo)** — Spring Boot 整合示例合集
- **[Hutool](https://github.com/dromara/hutool)** — Java 工具类库，极大简化开发

## 前端项目

- **[Element Plus](https://github.com/element-plus/element-plus)** — Vue 3 组件库
- **[Ant Design Vue](https://github.com/vueComponent/ant-design-vue)** — Vue 版 Ant Design

## 工具

- **[ChatGPT-Next-Web](https://github.com/ChatGPTNextWeb/ChatGPT-Next-Web)** — 一键部署私人 ChatGPT 应用
- **[Upscayl](https://github.com/upscayl/upscayl)** — AI 图片无损放大

## 学习资源

- **[CS-Notes](https://github.com/CyC2018/CS-Notes)** — 技术面试必备基础知识
- **[JavaGuide](https://github.com/Snailclimb/JavaGuide)** — Java 学习指南
- **[Hello-Algorithm](https://github.com/geekxh/hello-algorithm)** — 图解算法题典
- **[Free Programming Books](https://github.com/EbookFoundation/free-programming-books)** — 免费编程书籍合集

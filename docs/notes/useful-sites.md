# 常用网站

整理日常开发和学习中常用的网站资源。

## 技术社区

- **[GitHub](https://github.com/)** — 全球最大的代码托管平台
- **[Gitee](https://gitee.com/)** — 国内代码托管平台，访问速度快
- **[CSDN](https://www.csdn.net/)** — 中文技术社区
- **[掘金](https://juejin.cn/)** — 前端/后端技术文章
- **[SegmentFault](https://segmentfault.com/)** — 技术问答社区
- **[V2EX](https://www.v2ex.com/)** — 创意工作者社区

## 在线工具

- **[ProcessOn](https://www.processon.com/)** — 在线流程图、思维导图
- **[Draw.io](https://app.diagrams.net/)** — 免费在线绘图工具
- **[JSON.cn](https://www.json.cn/)** — JSON 格式化校验
- **[Carbon](https://carbon.now.sh/)** — 生成好看的代码截图
- **[CodePen](https://codepen.io/)** — 在线前端代码编辑器
- **[Regex101](https://regex101.com/)** — 正则表达式测试工具

## 图标与图片

- **[IconFont](https://www.iconfont.cn/)** — 阿里巴巴矢量图标库
- **[Unsplash](https://unsplash.com/)** — 免费高质量图片
- **[Shields.io](https://shields.io/)** — README 徽章生成

## API 文档

- **[DevDocs](https://devdocs.io/)** — 多语言 API 文档聚合
- **[Spring 官方文档](https://spring.io/projects/spring-boot)**
- **[MDN Web Docs](https://developer.mozilla.org/zh-CN/)** — 前端开发权威文档
- **[菜鸟教程](https://www.runoob.com/)** — 编程入门教程

## 学习平台

- **[B 站](https://www.bilibili.com/)** — 大量免费编程教程视频
- **[LeetCode](https://leetcode.cn/)** — 算法刷题平台
- **[牛客网](https://www.nowcoder.com/)** — 面试刷题与求职

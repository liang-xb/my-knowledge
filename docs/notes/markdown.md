# Markdown

Markdown 是一种轻量级标记语言，用纯文本格式编写文档，可轻松转换为 HTML。由 John Gruber 于 2004 年创建，已成为技术写作的事实标准。

## 为什么用 Markdown

- **纯文本**：任何编辑器都能打开，不依赖特定软件
- **易读易写**：语法简单，专注内容而非排版
- **版本控制友好**：纯文本便于 Git 追踪变更
- **多平台支持**：GitHub、Notion、语雀等都支持
- **导出灵活**：可转换为 HTML、PDF、Word 等格式

## 基础语法

### 标题

```markdown
# 一级标题
## 二级标题
### 三级标题
```

### 文本样式

```markdown
**加粗** 或 __加粗__
*斜体* 或 _斜体_
~~删除线~~
`行内代码`
```

### 列表

```markdown
- 无序列表项 1
- 无序列表项 2

1. 有序列表项 1
2. 有序列表项 2
```

### 链接与图片

```markdown
[链接文字](https://example.com)
![图片描述](image.png)
```

### 代码块

````markdown
```python
print("Hello, World!")
```
````

### 表格

```markdown
| 列1 | 列2 | 列3 |
|-----|-----|-----|
| A   | B   | C   |
```

### 引用

```markdown
> 这是一段引用文字
```

## 扩展语法

VitePress 和许多 Markdown 编辑器支持扩展语法：

```markdown
::: tip 提示
这是一个提示框
:::

::: warning 警告
这是一个警告框
:::
```

# Github 使用技巧

## 常见名词

- **repository** — 仓库，存放项目代码的地方
- **fork** — 复制他人的仓库到自己的账号
- **star** — 收藏/点赞感兴趣的项目
- **issue** — 问题追踪，可以在仓库中创建话题讨论
- **pull request** — 拉取请求，向仓库主人请求合并代码，完成协同开发
- **README.md** — 项目说明文档，通常包含项目介绍、安装使用步骤
- **.gitignore** — 配置哪些文件不需要被 Git 追踪
- **license** — 开源许可证，声明他人可以如何使用你的代码
- **releases** — 发布的版本，可以直接下载使用

## 搜索技巧

- **高级搜索**：在搜索结果页左下角有 `advanced search`，可以对搜索附加筛选条件
- **找百科大全**：`awesome xxx`
- **找示例项目**：`xxx sample`
- **找项目模板**：`xxx starter` / `xxx boilerplate`
- **找教程**：`xxx tutorial`

## 快捷操作

1. 按下 **t 键**，对仓库内的文件进行搜索，快速跳转
2. 按下 **l 键**，快速跳转到指定行号的代码
3. 按下 **b 键**，跳转到 blame 界面，查看文件的修改记录
4. 在仓库详情页按下 **句号键**，使用网页版 VS Code 打开项目
5. 在项目地址前加上 `gitpod.io/#/` 前缀，在线运行项目，自动识别项目类型并安装依赖

# 随笔

记录学习过程中的一些思考和感悟。

## 关于学习方法

学习编程最重要的是**动手实践**。看懂和会写之间隔着十万八千里，看教程觉得懂了，关掉视频就会发现无从下手。

- **少想多做** — 不要花太多时间纠结学什么，先动起来
- **降低预期** — 别指望几天速成，接受慢慢积累的事实
- **重视基础** — 基础不牢，后面全是空中楼阁
- **重复练习** — 好的代码写十遍都不嫌多

## 关于笔记

知识需要体系化存储。散落在各处的零碎笔记等于没有记。

记笔记不是为了给别人看，而是为了**未来的自己能快速回忆起来**。所以不用追求完美排版，但要追求：

- 清晰的结构
- 可复现的步骤
- 准确的术语

## 关于效率

工具只是手段，**思考才是核心**。不要花太多时间折腾工具和环境配置。

用 AI 辅助编程是趋势，但前提是自己得懂。AI 写出来的代码自己都看不懂，出了问题就无从下手。所以：

> 学习阶段 — 尽量手写，打好基础。工作阶段 — 善用工具，提高效率。

## 关于坚持

编程这条路没有捷径，唯一的方法就是：

1. 保持好奇心
2. 每天写一点代码
3. 遇到问题先自己查，实在不行再问别人
4. 定期总结复盘

# Markdown 语法

Markdown 是一种轻量级标记语言，用纯文本格式编写文档。

## 标题

```md
# 一级标题
## 二级标题
### 三级标题
#### 四级标题
```

## 文字样式

```md
**粗体文字**
*斜体文字*
~~删除线~~
`行内代码`
```

## 列表

**无序列表**

```md
- 项目 1
- 项目 2
  - 子项目 2.1
```

**有序列表**

```md
1. 第一步
2. 第二步
3. 第三步
```

## 链接与图片

```md
[链接文字](https://example.com)

![图片描述](https://example.com/image.png)
```

## 引用

```md
> 这是一段引用文字
> 可以多行
```

## 代码块

````md
```java
public class Hello {
    public static void main(String[] args) {
        System.out.println("Hello World");
    }
}
```
````

## 表格

```md
| 列1 | 列2 | 列3 |
|-----|-----|-----|
| A   | B   | C   |
| D   | E   | F   |
```

## 分隔线

```md
---
```

## 任务列表

```md
- [x] 已完成任务
- [ ] 待完成任务
```

## 常用技巧

- **换行**：行末加两个空格或空一行
- **转义**：用 `\` 转义特殊字符如 `\*`
- **HTML**：Markdown 支持内嵌 HTML 标签

# Markdown @ Emoji

在 Markdown 中使用 Emoji 表情，让文档更生动。

## 直接输入 Emoji

Windows 快捷键 `Win + .`（句号键），Mac 快捷键 `Control + Command + 空格`。

## 常用 Emoji 速查

### 标识

| Emoji | 代码 | 含义 |
|-------|------|------|
| ⚠️ | `:warning:` | 警告 |
| 💡 | `:bulb:` | 提示 |
| ✅ | `:white_check_mark:` | 完成 |
| ❌ | `:x:` | 错误 |
| 🔴 | `:red_circle:` | 红色标记 |
| 🟢 | `:green_circle:` | 绿色标记 |

### 状态

| Emoji | 代码 | 含义 |
|-------|------|------|
| 🚀 | `:rocket:` | 发布 / 部署 |
| 🔥 | `:fire:` | 热门 / 重要 |
| ⭐ | `:star:` | 收藏 |
| 📝 | `:memo:` | 笔记 |
| 🔧 | `:wrench:` | 修复 / 工具 |
| 🐛 | `:bug:` | Bug / 问题 |

### 技术

| Emoji | 代码 | 含义 |
|-------|------|------|
| 💻 | `:computer:` | 代码 / 开发 |
| 📦 | `:package:` | 包 / 依赖 |
| ⚡ | `:zap:` | 性能 / 快速 |
| 🔒 | `:lock:` | 安全 |
| 📚 | `:books:` | 文档 / 学习 |
| 🎯 | `:dart:` | 目标 |

### 学习

| Emoji | 代码 | 含义 |
|-------|------|------|
| 👨‍💻 | `:technologist:` | 程序员 |
| 📖 | `:book:` | 阅读 |
| ✍️ | `:writing_hand:` | 练习 |
| 💪 | `:muscle:` | 加油 |
| 🎉 | `:party popper:` | 庆祝 |

## 常见写法示例

```md
## 🚀 快速开始

> ⚠️ 注意：请先安装 Node.js

### 📦 安装依赖
npm install

### ✅ 完成
项目已成功启动 🎉
```

## 小技巧

- 不要过度使用，适量点缀即可
- 标题加 Emoji 有助视觉区分
- Commit 信息中加 Emoji 也是常见做法

# 前端四件套

前端开发的核心四件套：HTML、CSS、JavaScript、TypeScript。

## 四件套概览

| 技术 | 作用 | 类比 |
|------|------|------|
| HTML | 页面结构 | 骨架 |
| CSS | 页面样式 | 皮肤 |
| JavaScript | 页面交互 | 肌肉 |
| TypeScript | 类型安全 | 铠甲 |

## 学习路线

```
HTML → CSS → JavaScript → TypeScript
```

### 第一阶段：HTML + CSS

- 掌握常用 HTML 标签
- 理解盒模型
- 掌握 Flex 和 Grid 布局
- 能做静态页面

### 第二阶段：JavaScript

- 基本语法和数据类型
- DOM 操作
- 事件处理
- ES6+ 新特性
- 异步编程（Promise、async/await）

### 第三阶段：TypeScript

- 类型注解
- 接口和泛型
- 常用工具类型
- 在项目中应用
